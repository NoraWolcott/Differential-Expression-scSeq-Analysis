# Differential-Expression-scSeq-Analysis

A pipeline for differential gene expression and pathway analysis of RNA-seq data. This repository uses Scanpy for differential expression and GSEApy for gene set enrichment analysis, followed by visualization and gene-level analysis of enriched biological programs.

## Requirements

* Jupyter Notebook (Python)

## Reference

Wolf, F., Angerer, P., & Theis, F. (2018). SCANPY: large-scale single-cell gene expression data analysis. Genome Biology, 19, 15. https://doi.org/10.1186/s13059-017-1382-0

Fang, Z., Liu, X & Peltz, G. (2023). GSEApy: a comprehensive package for performing gene set enrichment analysis in Python. Bioinformatics, 38(13), 3957–3958. https://doi.org/10.1093/bioinformatics/btac757
